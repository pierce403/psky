# Management console validation, 2026-09-15

Scope: local operator tooling and read-only peer observations. This does not
prove live repository persistence, signer custody, or Bluesky client support.

## Automated checks

- 117 Rust tests passed: 43 operator-library, 8 CLI, 32 peer-fixture,
  32 repository, and 2 Rustdoc examples.
- 6 dependency-free console state tests passed. These use a DOM/fetch fixture,
  not a real browser: token handling, dirty edits and reconnect, configuration
  races, disconnected requests, restart cursors, and safe text rendering.
- Strict Clippy, formatting, whitespace, and Rustdoc checks passed.
- Four CARs generated by the console's offline action passed the pinned official
  ATProto verifier, including negative signature, CID and truncation checks.

Reproduce with the commands in [getting started](../getting-started.md) plus
`node --test scripts/console.test.mjs`. CI runs both suites and the independent
CAR verification in [.github/workflows/rust.yml](../../.github/workflows/rust.yml).

## Browser and API checks

An isolated loopback console with a disposable test token was exercised in the
in-app browser. Verified authenticated rendering, live peer checks, offline
action completion, event history, preserving unsaved edits during refresh,
saving settings, and pending listener changes. Restart preserved the settings
revision and applied the new public port. The updated assets were then reloaded.

The narrow 390-pixel layout rendered without document-level horizontal overflow.
The 1440-pixel desktop breakpoint also had no document overflow. No browser
warnings or errors were captured during the check.

The normal development console was started on 127.0.0.1:8788 with its existing
private token. Its served `/llms.txt` matched the source file byte-for-byte.
Public `/health` returned 200 and `/ready` correctly remained 503.

- Majin: Hypersnap active, snapshot 840/5,640 chunks, reported 14%, API resetting
  connections during bootstrap. About 6.8 TB free on the data volume. No service

- Haatz: version 0.13.5, three shards reporting 0-second delay.
- PublicProof: version 0.13.5 and a different reported peer ID, but about

and PublicProof lagging. These are snapshots of self-reported state, not proof
of full sync or independent failure domains. Two fresh usable nodes were not
